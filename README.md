# HKType 粵拼打字遊戲

單頁靜態網站，學廣東話拼音打字。開 `index.html` 即玩，亦可經 GitHub Pages 上網玩。

## 版面（全部單行，唔會另起新行）

- 頂欄一行過：**打字 / 詞語 / 錯題庫 / 識字庫** ＋右手邊 **粵拼 / 倉頡 / 速成**三掣＋**日間/夜間**
- 闊畫面：左邊打字卡，**右欄由上而下黐埋一齊零間距＝分數＋級別融合成一嚿 → 粵拼係成嚿玩法指南（下面嗰段原文搬過去，左下角唔再顯示；倉頡/速成指南留返左下角） → 倉頡字母及輔助字形卡（縮細，一版睇晒 24 張，只喺倉頡/速成出現）**，成欄黐住跟碌
- 級別（初級/中級/高級/地獄/混合）下面保留 **已完成 percentage**；**已做按輸入法分開計**（粵拼做咗幾多唔會溝埋倉頡，每個輸入法獨立進度）
- 答完檢查會自動碌去回饋位，錯咗咩同正確答案一定睇到

## 玩法

- **輸入法切換**：頂部可轉 **粵拼 / 倉頡 / 速成**，打字、詞語、錯題練習全部跟住轉
  - 粵拼：睇字打拼音（唔使聲調，如 `luk` = 綠）
  - 倉頡：睇字打倉頡五代**全碼**（如 明 = `ab` 日月）
  - 速成：同倉頡拆法，只打**頭＋尾**兩碼（如 你 = `of` 人火，龍 = `yp` 卜心）
- **打字**：睇住個中文字，用當前輸入法打出編碼
- **詞語**：逐字打編碼，用空格分開（如香港倉頡 → `hda etcu`，速成 → `ha eu`）
- **錯題庫**：錯咗自動記低（按輸入法分開記：拼/倉/速徽章），可重練，撳表頭轉排序
- **識字庫**：答啱自動記低（按輸入法分開記），連「試咗幾多次先啱」都記低
- **內置鍵盤**：每道題下面都有鍵盤（粵拼 A–Z；倉頡/速成顯示字根＋字母），手機會自動禁彈出系統鍵盤，直接撳就得；撳「切換系統鍵盤」可用返自己鍵盤；有實體鍵盤照打得
- **倉頡字母及輔助字形卡**：轉倉頡/速成會自動展開，四色分類（哲理/筆畫/人身/字形），每張卡有主根＋輔根變體＋字母（附讀音如斜點交叉縱橫鈎），闊畫面會自動移去左欄黐住跟碌，邊睇邊打；撳字母卡即打入嗰個字母

## 規則

- 難度：初級 / 中級 / 高級 / 地獄 / 混合
- 讀音以詞庫多數實際用法為準（自動修正咗約 900 個生僻標音，如 芒 mong、費 fai、佬 lou、佢 keoi）；多音字打邊個啱讀音都收
- 四級由大詞庫自動分級：打字用單字（初級約 3 千真常用字、中級約 2.5 千、高級約 1.3 千、地獄約 2 萬罕字）；詞語模式用詞，每級約 2–3 萬題
- 詞庫：約 2.7 萬單字 + 9.9 萬詞語（CanCLID rime-cantonese 詞庫，CC-BY 4.0），混合唔重複出；倉頡碼表嚟自 rime-cangjie《五倉世紀》（GPL，原作 chinesecj.com／惜緣／佛振），本站只收錄詞庫所需約 2.7 萬字，速成碼由頭尾自動衍生
- 答啱唔會再出（識字庫按輸入法獨立排除），答錯隔幾題再出直到啱為止
- 答啱 1 秒後自動下一題，答錯停低慢慢睇
- 所有記錄存瀏覽器 localStorage，唔使 login

## 開網站（GitHub Pages）

Settings → Pages → Deploy from a branch → main / root → Save，
之後用 `https://<username>.github.io/hktype/` 開，手機電腦都得。
